# Lesson 5 Project
You’re starting to get into the meat of HTML, learning how to format pages using CSS. You’ll use inline CSS in this lesson to demonstrate color methods, fonts, and font families. Think about how the styles you apply will appear to a user, keeping in mind that this page in your portfolio will demonstrate that you know how to apply styles, as well as that you understand why you’ve made your styling choices.

## Project Prep
1. If you haven't done so already, clone the repo to your computer within your course folder.
2. Open the repo within VS Code. You can open this `readme.md` file within VS Code to view the project directions there. 

   > **TIP:** Right click on the file and choose the `Open Preview` option.

## Part 1: Create an Inline CSS Page
1. Open the **template.html** file.

0. Save the template.html file as a new file in your Lesson 5 course folder with the name: **inline_css.html**

0. In the Head section, update the **multi-line comment** as needed to match the information for this lesson. 
0. In the Head section, update the **metadata** with the following information:

0. In the header section, comment out the **navigation menu**.

0. In the Main section, edit the placeholder content so that there are **two (2) paragraphs** with a **second level-heading** above each paragraph. Edit the placeholder text with the following information:
    - In the first paragraph, briefly explain the difference between the generic font families.
    - In the second paragraph, briefly explain the different color methods. 
    - Add appropriate text for each second-level heading that appropriately summarizes each paragraph.

## Part 2: Apply Inline CSS
Apply CSS directly to the appropriate HTML element to complete the following steps.
    
1. Center align *all elements* within the **header**. Do this with the least number of inline styles as possible. 

0. Style the **first-level heading** within a single declaration block based upon the following criteria:    
    - Apply a color of your choosing using the hexadecimal method.
    - Change the font size using an absolute value.
    - Apply a family of fonts.

0. Add an **HTML comment** before the first-level heading to explain what would happen if the first font listed is not available to the end user, using your selected fonts as a guide.

0. Modify the font weight of the **slogan paragraph** within the page header to make it bold in appearance.

0. Add an **HTML comment** before the slogan paragraph to identify all three types of values that can be used to define a font-weight property.

0. For each of the **second-level headings**:
    - Apply a color of your choosing to the first heading using the color names method.
    - Apply a color of your choosing to the second heading using the RGB method.

0. For the first **paragraph** within the main section, use the font shorthand property to:
    - Increase the font size using a relative value.
    - Apply a set of sans-serif styled fonts.

0. For the second **paragraph** within the main section, use the font shorthand property to:
    - Apply a font style.
    - Increase the font size by applying a value of the length in pixels.
    - Apply a set of monospace styled fonts.
    

0. Right align *all elements* within the **footer**. Do this with the least number of inline styles as possible.
